# Customer Churn Prediction

## 📌 Project Overview

This project aims to predict customer churn in a telecommunications dataset using machine learning techniques. The model classifies customers into two categories: **Churn** and **Non-Churn**.

Customer churn means a customer is likely to leave the service, while non-churn means the customer is likely to continue using the service. This prediction helps businesses identify high-risk customers early and take retention actions.

## 🎯 Objective

* Predict whether a customer belongs to **Churn** or **Non-Churn**
* Identify customers who are likely to leave the service
* Achieve high model accuracy (target > 90%)
* Support business decision-making for customer retention
